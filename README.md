# InsureTrack — Insurance Policy Claims Management System

## About the Project

InsureTrack is a Java-based Insurance Policy Claims Management System developed as a DBMS project. It helps manage customers, insurance policies, claims, payments, and insured assets through a desktop application.

This repository contains two versions of the project, developed using different database technologies.

## Projects

### Project 1 — DA2
- **Database:** Oracle Database
- **Technologies:** Java, Java Swing, SQL, PL/SQL, JDBC
- **Focus:** Relational database design, normalization, and database programming.

### Project 2 — DA3
- **Database:** Neo4j
- **Technologies:** Java, Java Swing, Cypher, Neo4j Java Driver, Maven
- **Focus:** Graph databases, connected data, and graph-based queries.

## Key Features
- Customer and policy management
- Insurance claim management
- Payment and asset management
- Create, read, update, and delete (CRUD) operations
- Database connectivity and query execution
